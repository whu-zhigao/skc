# SKC Artifact — Code and Data for Verification

Anonymous artifact for the ICDE submission
**"SKC: A Bounded-Dispersion Cache Architecture for Model-Derived State in
Recommendation Serving"** (2026-11 build).

Everything needed to verify the paper's numbers is in this repository:
source code, experiment drivers, and every result JSON the tables and macros
summarize. Datasets and model checkpoints are excluded (third-party / large
binaries); Section "Regenerating excluded assets" explains how to rebuild
them.

## Layout

```
systems/           core library + benchmark drivers (one bench_*.py per study)
experiments_icde/  experiment suite that produced the result JSONs
mplignn/           model package (encoder, cross-attention, training loop)
analysis/          summarize_revision_results.py (JSON -> tex macros),
                   verify_paper_numbers.py (asserts paper numbers == JSONs)
tests/             unit tests incl. page-consistency protocol tests
results/           ALL result JSONs referenced below (npz = actual-model drift traces)
figures/           plotting scripts for every paper figure (incl. the
                   editable Fig. 1 architecture source)
tools/             check_layout.py (PDF page/limit self-check)
docs/              run protocols, backfill report, revision result logs
```

Macros: `paper/revision_generated.tex` is machine-generated by
`analysis/summarize_revision_results.py` from these JSONs; no number in the
tables is hand-transcribed. `analysis/verify_paper_numbers.py` asserts the
headline numbers against the JSONs and exits nonzero on mismatch.

## Verifying the paper's numbers

```bash
python3 analysis/verify_paper_numbers.py     # asserts headline numbers
python3 analysis/summarize_revision_results.py  # regenerates the tex macros
```

Both run CPU-only in seconds. To re-run a full study, see the driver listed
in the table above; each accepts `--data/--ckpt` paths and writes the same
JSON schema under `results/systems/`.

## Regenerating excluded assets

- **Datasets** (`diginetica.pkl`, `gowalla.pkl`, `yoochoose_quarter.pkl`):
  build from the public sources (Diginetica/CIKM16 Cup, Gowalla check-ins,
  Yoochoose/RecSys Challenge 2015) with the preprocessing in
  `experiments_icde/README.md` (sessions ≥ 2 items, items with frequency ≥ 5,
  next-item target). The datasets are third-party and are not redistributed.
- **Model checkpoints** (`results/real/*.pt`): train with the A3 co-training
  protocol (30 epochs × 40 mini-batches, batch 256) described in §VI-A;
  `mplignn/` contains the full model and training loop. Consecutive-epoch
  item-drift traces are produced by the same run (`a3/*.npz` schema).
- **Exact-neighbor arrays** (`*.npy`): regenerate with
  `systems/bench_retrieval.py --exact` per dataset.

## Hardware note

A800 results (source placement, CUDA publication stress, SLA replay) were
produced on 1×A800-80GB (14 vCPU Xeon Gold 6348, 120 GB RAM). The JSONs
record device and protocol metadata; CPU-only reproduction covers everything
else.
